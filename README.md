# twciv：臺灣各縣市互動式文明地圖（繁體中文版）

以 4X 策略遊戲地圖風格呈現真實臺灣：六角格地形、中央山脈百岳高山、淺海臺灣海峽與深邃太平洋、22 縣市與 368 鄉鎮市區公開統計數據、發電廠、商港機場與臺灣奇觀，全數由原生 ES Modules + Canvas 2D 與 Python 標準函式庫資料管線建構（無需 npm 或打包步驟）。

改編自 Karpathy 的 MIT 開源專案 `usaciv`。

## 功能一覽

- **臺灣六角格地形地圖**：採臺灣中心 Albers 等面積投影（121°E, 23.7°N），切分為 76×108 網格（1,247 個臺灣陸地六角格，涵蓋本島、澎湖、金門與馬祖），地形與海洋水深取自 NOAA ETOPO1 1 弧分（約 1.8 km）高程資料。
- **10 種互動地圖濾鏡（368 鄉鎮市區＋22 縣市）**：人口密度、家庭可支配所得、大專以上學歷、65 歲以上高齡比例、2021–2024 人口成長率、房價所得比、年齡中位數、單人戶比例、地形海拔與森林覆蓋。支援圖例直方圖區間拖曳篩選。
- **22 縣市與都會面板＋城市視角**：點擊任一縣市或城市橫幅即可檢視五大產出排名、人口變化、每戶可支配所得、房價所得比、失業率與市民年齡／學歷結構。
- **能源、交通與奇觀圖層**：20 座主力發電廠與離岸風光電場、381 段公路、220 段鐵路、7 大國際商港、9 大機場與 23 座臺灣奇觀（國家公園、頂尖研究型大學、代表性地標）。
- **8 大繁中顧問面板**：能源與電廠、經濟產值、人口與高齡、所得與房價、教育與科技、地形與土地、奇觀與文化、資料探索器，全面與地圖雙向聯動。
- **中文搜尋（支援臺／台互通）與資料年鑑**：按 `/` 或 `⌘K` 即時搜尋縣市，點選右上角「資料年鑑」可查閱每項指標的官方資料來源與口徑說明。

## 快速啟動

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory web
# 開啟瀏覽器前往 http://127.0.0.1:8766/
```

## 重新建置資料與執行測試

```bash
python3 pipeline/build_twciv.py
python3 -m unittest tests/test_twciv.py
```

## 資料來源與口徑說明

- **行政區界**：內政部國土測繪中心 TGOS TopoJSON（經 `taiwan-atlas` 發布），涵蓋 22 縣市與 368 鄉鎮市區。
- **高程與水深**：NOAA NCEI ETOPO1 1 弧分全球地形模型（經 ERDDAP 下載）。
- **人口、面積、年齡、學歷、家戶**：內政部戶政司開放資料 API（`ODRP048` 110–113年、`ODRP031/113`、`ODRP020/113`、`ODRP025/113`）。註：`ODRP031/113` 原始檔缺少新北市板橋區單歲年齡，依原則留空不估算。
- **經濟、所得、房價與就業**：財政部營利事業銷售額（112年，作縣市經濟規模指標）、行政院主計總處家庭收支調查與 113 年人力資源調查（金門／連江未納抽樣故留空）、內政部 113Q4 房價負擔能力指標（離島三縣未單獨發布故留空）。
- **交通、能源與奇觀**：Natural Earth 1:10m 公路／鐵路、台灣電力公司與能源署、臺灣港務公司、交通部民航局、內政部國家公園署與教育部。
